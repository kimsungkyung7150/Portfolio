# 하루 실제 동작 시연 — 2026-10-24

기존 정지 캡처 영상과 별도로, 브라우저의 연속 화면 프레임을 촬영한 1분 38초 시연을 제공합니다. 1920×1080 / H.264 / 24fps, 한국어 화면 설명과 선택 자막, 텍스트 설명을 포함합니다. 자동 재생하지 않으며 PC의 Memory OS 서버가 꺼져 있어도 공개 포트폴리오에서 재생됩니다.

## 실제 시연의 범위

이번 HTML 보고서 공개 작업을 새 업무로 한 번 제출했습니다. Writer 접수 후 다른 ChatGPT 대화에서 변경 이유와 이전·이후 상태를 질문하고, 같은 작업의 수정 파일·작업자·남은 일을 후속 질문으로 확인했습니다. 같은 원문 한 건만 비공개 인수인계로 생성하고 전체 3부를 조회했습니다.

| 단계 | 확인한 결과 |
| --- | --- |
| Writer | 새 보고서 1건 ACCEPTED. SQL 원문 UTF-8 2,373바이트 및 SHA256 일치 |
| 회상·후속 | 색인 대기 중 저장된 원문을 직접 조회하여 설명. 이 장면을 하루의 새 ANSWERED 생성 성공으로 계산하지 않음 |
| 인수인계 | PRIVATE, COMPLETED 3/3. 수집 근거 62개, 누락 0개 |
| 문서 재조회 | 전체 Markdown 30,424바이트. MCP 3부와 SQL 문서 바이트·해시 일치. 재조회는 모델 재호출 0건 |
| 보존 | 기존 보호 UNKNOWN 6건의 SQL 행 불변. 소비한 보류 및 실패·중단 입력을 다시 보내지 않음 |

자동 처리 이후 본문·벡터·전문 검색 색인은 READY로 관측됐으나 자동 정리의 SEARCH_PENDING 및 문서의 PARTIAL_CONTEXT 안내는 남아 있습니다. 현재 영상은 해당 질문 시점의 원문 조회와 문서 저장 경로를 보여줍니다. B43 FAIL과 미확정 벡터 1개, 팀원·새 장치 미검증 범위는 그대로입니다.

## 촬영과 편집

- ChatGPT의 실제 입력·전송·응답 확인과 HTML 목차 이동·원문 펼치기를 CDP screencast 연속 프레임으로 촬영했습니다. 생성 이미지나 입력·답변을 흉내 낸 애니메이션을 사용하지 않았습니다.
- 장면 사이의 처리 대기를 줄이고 읽기 시간을 조정했습니다. 무편집 실시간 응답 속도를 나타내는 영상이 아닙니다.
- 클릭 강조는 실제 UI 클릭 시각·좌표 로그에 연결한 편집 효과입니다. 제품 상태나 답변을 바꾸지 않았습니다.
- 브라우저 메뉴·계정 영역은 제외하고 별명과 보고서·접수 식별자는 불투명하게 가렸습니다. CDP의 CSS 좌표와 JPEG의 픽셀 배율을 맞춰 가림을 적용했습니다.
- 끝의 HTML은 이번에 저장한 같은 업무의 Markdown 3부를 편집한 별도 공개 열람본입니다. Memory OS의 새 서버 출력 기능으로 소개하지 않습니다. 보고된 구현 검사와 직접 대조한 저장 결과를 구분합니다.
- 원본 촬영 프레임, 단계별 타임스탬프·해시·편집 명세, SQL 및 MCP 응답과 가림 대응표는 비공개 증거 폴더에 보존합니다. 공개 소스에는 포함하지 않습니다.

## 배포 전 확인

- 최종 영상 98초, 1920×1080, 24fps, 전체 2,352프레임. 선택한 촬영 원본은 연속 프레임 351개입니다.
- 전체 영상 디코드, `npm run lint`, `npm run build` 통과.
- 실제 브라우저 재생·한국어 자막 표시와 390px 모바일 배치를 확인했습니다. 공개 영상·자막·설명·HTML은 정적 파일입니다.
- 로컬 영상 부분 요청은 HTTP 206, 자막·설명·HTML·공개 원문은 HTTP 200으로 확인했습니다.

## 모바일 열람 보완 · 2026-10-24

PC Chromium 브라우저의 360×800, 390×844, 844×390 화면과 1280×720 데스크톱 크기로 검수했습니다. 실제 휴대폰으로 실행한 결과와 구분합니다.

- 영상 아래에 44px 높이의 한국어 자막·전체화면 버튼을 추가했습니다. 기본 재생 컨트롤과 `playsInline`, 자동 재생하지 않는 정책은 유지했습니다. 자막의 켜짐 상태는 브라우저의 실제 텍스트 트랙 상태와 연결합니다.
- 98초 영상의 재생 진행, 한국어 자막 표시·끄기, 전체화면 진입·복귀를 브라우저에서 확인했습니다. 작은 화면에는 전체화면·가로 보기 안내와 직접 읽을 수 있는 보고서 링크를 제공합니다.
- 두 HTML 보고서의 모바일 본문은 15px, 검증 목록·원문 발췌는 14px로 표시됩니다. 요약·원문·인쇄 도구는 최소 44×44px이며, 가로 모바일에서도 읽기용 단일 열을 유지합니다. 네 화면 크기 모두 가로 넘침이 없고 원문 펼치기가 동작했습니다.
- 영상, 자막 파일, 포스터, 시연 설명, 두 공개 Markdown 사본의 SHA256은 수정 전과 같습니다. 두 HTML의 본문·발췌·상태·스크립트도 동일하며 CSS만 수정했습니다. 개인정보 가림과 실제 동작의 설명 범위를 변경하지 않았습니다.
- `npm run lint`, `npm run build`를 통과했습니다. 이 검수는 추가 모델 호출이나 SQL 데이터 변경을 실행하지 않습니다.

실제 iPhone/Safari와 Android/Chrome의 기기 회전, 네이티브 전체화면·자막 겹침, 터치 사용감은 아직 실기기로 확인하지 않았습니다. 특히 브라우저의 화면 크기 변경은 실제 OS의 네이티브 동영상 화면을 재현하지 않으므로 실기기 합격으로 표시하지 않습니다.
