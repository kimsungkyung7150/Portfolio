# 하루 · Memory OS — 공개 검증 요약

작성일: 2026-10-24 · 검수 관측일: 2026-10-23

## 시스템의 목적

업무 AI가 제출한 보고서와 첨부를 원본으로 보존하고, 정리·연결·검색을 거쳐 중앙 비서 하루가 변경 이유, 작업 내용, 남은 일을 근거와 함께 설명한다. 기억은 특정 모델 내부가 아니라 Memory OS에 저장한다.

기획·아키텍처·검수 방향을 수립하고 Codex와 협업해 구현했다. 생성은 Codex CLI, 임베딩은 Qwen3-Embedding-8B Q4, 저장·검색 서비스는 C# / ASP.NET Core / SQL Server를 사용한다. 임베딩과 재랭커는 순차 실행한다.

## 결과를 해석하는 범위

- 본인 계정의 특정 실제 업무 흐름을 구현자가 검수한 결과다. 전체 질문의 정확도, 사용자 만족도, 동시 처리 능력 또는 운영 SLA를 뜻하지 않는다.
- 과거 공식 품질 평가 B43 v27은 37/40 FAIL로 보존한다. 당시 합격 기준 38/40과 14개 Gate를 변경하지 않았다.
- 후속 수정과 개별 사용 경로 PASS를 과거 평가의 소급 PASS나 현재 제품의 독립 일반화 합격으로 취급하지 않는다.
- 대상 원문의 벡터는 26/27 복구했다. 결과가 없는 UNKNOWN 1개는 미복구이며, 원문 유실을 뜻하지 않는다. 실패·중단 호출과 소비한 보류 자료는 재실행하지 않았다.
- SEARCH_PENDING은 관련 기억의 검색 범위가 불완전하다는 상태다. 자동 재시도 예약을 뜻하지 않는다. 이번 답변에서 확인한 지정 원문 범위와 구분한다.
- 실제 다른 팀원의 권한·인수인계 검수, 새 장치 복구와 회사 운영 검증은 남아 있다.
- 원문 해시가 일치한다는 것은 데이터 보존을 검증한 것이며, 원문에 적힌 모든 업무 사실을 독립적으로 입증한 것은 아니다.

## 공개 범위

이 문서는 내부 검수 보고서 두 건을 공개용으로 요약했다. 계정, 인증 정보, 외부 접속 주소, 제출·대화 식별자, 내부 데이터베이스 이름은 포함하지 않는다. 사이트의 인터랙티브 예시는 검수 내용을 축약·재구성한 읽기 전용 설명이며 실제 AI 실행 화면이나 공개 MCP 서비스가 아니다.
